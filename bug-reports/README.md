# Bug Reports

Use [`bug-report-template.md`](./bug-report-template.md) for defects that have been reproduced and compared with an agreed expected result. No confirmed application bugs are currently recorded in this portfolio.

A failed automated test is a signal, not automatically a software defect. First determine whether the failure came from the application, an outdated locator or assertion, unavailable test data, browser/environment instability, or the automation code itself. Record an application bug only after investigation supports that classification; otherwise update the test or document the environmental issue.

Before committing evidence, remove credentials, personal information, session identifiers, database content, and other sensitive data.
